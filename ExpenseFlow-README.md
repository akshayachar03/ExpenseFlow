# ExpenseFlow

ExpenseFlow is a modern full-stack expense management application that helps users track income and expenses, organize transactions using categories, and view financial summaries through an interactive dashboard.

> **Project Status:** 🚧 Development (Version 1.0)

---

## Features

- User Registration & Login
- JWT Authentication
- Dashboard with Financial Summary
- Income & Expense Tracking
- Category Management
- Reports & Analytics
- Responsive Material UI Interface

---

## Installation

### Clone the repository

```bash
git clone git@github.com:akshayachar03/ExpenseFlow.git

cd ExpenseFlow
```

---

### Install dependencies

```bash
npm install
```

Install frontend dependencies

```bash
cd frontend
npm install
```

Install backend dependencies

```bash
cd ../backend
npm install
```

---

## Run the Application

### Start Backend

```bash
cd backend
npm run dev
```

Backend runs on:

```
http://localhost:5000
```

---

### Start Frontend

```bash
cd frontend
npm run dev
```

Frontend runs on:

```
http://localhost:5173
```

---

## Environment Variables

Create a `.env` file inside the **backend** directory.

Example:

```env
PORT=5000

MONGODB_URI=your_mongodb_connection_string

JWT_SECRET=your_secret_key
```
